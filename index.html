Methodology & limitations

Area is calculated from valid feature geometry using Turf.js. If the input uses projected coordinates, export it from QGIS or ArcGIS as GeoJSON in WGS 84 (EPSG:4326).

Net area difference is not necessarily the newly developed land area. True change mapping requires spatial overlay between the 2013 and 2023 geometries.

This is exploratory screening, not independent validation of source classifications or SDG 11 compliance.
